# Daedalus Bridge

Daedalus Bridge is a lightweight Godot editor communication plugin. It connects an open Godot project to Daedalus Backend and exposes editor context and approved editor tools to Daedalus Studio.

The plugin does not include chat, sessions, model settings, approvals, plans, skills, MCP configuration, or diff review. Those experiences live in Daedalus Studio.

## Requirements

- Godot 4.0 or newer
- Daedalus Studio and Backend versions that support Editor Bridge Protocol v4

Install the `addons/daedalus_bridge` directory and enable **Daedalus Bridge** in Project Settings, under Plugins.
